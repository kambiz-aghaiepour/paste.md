<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> POST /api/paste | Untrusted user content crosses into server-side storage |
| Browser -> GET /[slug] | User-controlled slug parameter used in database query |
| Database -> Browser | Stored user content rendered in HTML response |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Denial of Service | POST /api/paste | mitigate | Validate content size server-side with TextEncoder byte counting; reject >512KB with 413 (D-12) |
| T-01-02 | Tampering | POST /api/paste | mitigate | Validate content is non-empty string; reject invalid JSON with 400; parameterized queries via Drizzle ORM prevent SQL injection |
| T-01-03 | Information Disclosure | GET /api/paste/[id] | mitigate | nanoid(8) generates cryptographically random slugs (D-01); 281T combinations prevent enumeration |
| T-01-04 | Information Disclosure | data/paste.db | mitigate | .gitignore excludes database files; SQLite file stored outside public directory; not served as static asset |
| T-01-05 | Spoofing | app/[slug]/page.tsx | mitigate | Render user content in pre tag (text node), never via dangerouslySetInnerHTML; no HTML interpretation of stored content |
| T-01-06 | Elevation of Privilege | lib/db/index.ts | accept | Single-user SQLite with no authentication -- all pastes are public by design. No privilege boundaries to cross. |
</threat_model>
