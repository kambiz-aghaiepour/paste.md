    Create two test files covering all 6 phase requirements.

    1. Create tests/lib/db.test.ts -- database layer unit tests:

       - STOR-01 test: "pastes table has correct schema including expires_at"
         Import `db` from `@/lib/db` and run a raw pragma query `PRAGMA table_info(pastes)` via the underlying better-sqlite3 connection (access via `db.$client`). Assert 5 columns exist: `id` (TEXT), `content` (TEXT), `created_at` (INTEGER), `expires_at` (INTEGER), `size_bytes` (INTEGER). Assert `id` column has `pk = 1`.

       - STOR-01 test: "database is in WAL mode"
         Query `PRAGMA journal_mode` via `db.$client.pragma('journal_mode')`. Assert result is `'wal'`.

       - CORE-04 test: "createPaste stores and retrieves paste with valid data"
         Import `createPaste` and `getPasteById` from `@/lib/db/queries`. Create a paste with `id: 'test1234'`, `content: 'test content'`, `createdAt: Math.floor(Date.now() / 1000)`, `expiresAt: null`, `sizeBytes: 12`. Assert the returned paste has all fields matching. Retrieve with `getPasteById('test1234')` and assert it matches. Use `afterEach` to clean up test records by deleting from pastes where id starts with 'test' (import `like` from `drizzle-orm` and `pastes` from schema).

       - Test: "getPasteById returns undefined for non-existent id"
         Call `getPasteById('nonexistent')`. Assert result is `undefined`.

    2. Create tests/api/paste.test.ts -- API route integration tests:

       Import the `POST` handler from `@/app/api/paste/route` and the `GET` handler from `@/app/api/paste/[id]/route`. Also import `GET` from raw route. Test by constructing Request objects directly and calling the exported handler functions (no HTTP server needed).

       - CORE-01 test: "POST /api/paste creates a paste and returns id + url"
         Create a `new Request('http://localhost/api/paste', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ content: 'Hello world' }) })`. Call `POST(request)`. Assert status 201. Parse JSON body. Assert `id` is a string of length 8. Assert `url` matches pattern `/${id}`. Clean up: delete the created paste from DB.

       - CORE-02 test: "created paste url starts with /"
         From the POST response, assert `url` starts with `/` and is `/${id}`.

       - CORE-04 test: "paste id is 8 characters, URL-safe"
         From the POST response, assert `id.length === 8` and `id` matches regex `/^[A-Za-z0-9_-]+$/`.

       - SECU-04 test: "rejects content exceeding 512KB with 413"
         Create a request with content of 512 * 1024 + 1 bytes (use `'x'.repeat(512 * 1024 + 1)`). Call POST. Assert status 413. Assert JSON body contains `error` field.

       - Test: "rejects empty content with 400"
         Create a request with `{ content: '' }`. Call POST. Assert status 400.

       - Test: "rejects missing content with 400"
         Create a request with `{}`. Call POST. Assert status 400.

       - Test: "rejects invalid JSON with 400"
         Create a request with non-JSON body. Call POST. Assert status 400.

       - CORE-03 test: "GET /api/paste/:id returns paste data"
         First create a paste via POST. Then construct a GET request and call the GET handler with `{ params: Promise.resolve({ id: createdId }) }`. Assert status 200. Assert JSON has `id`, `content`, `created_at`, `expires_at` fields.

       - Test: "GET /api/paste/:id returns 404 for non-existent paste"
         Call GET with `{ params: Promise.resolve({ id: 'notexist' }) }`. Assert status 404.

       - Test: "GET /api/paste/:id/raw returns plain text"
         Import GET from raw route. Create a paste, then call raw GET handler. Assert status 200. Assert Content-Type header contains `text/plain`. Assert response body text equals the original content.

       Use `afterEach` or `afterAll` to clean up test records from the database.

    3. Add a `"test"` script to package.json if not already present: `"test": "vitest run --reporter=verbose"`
