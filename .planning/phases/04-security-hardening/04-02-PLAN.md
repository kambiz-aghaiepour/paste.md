<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> Proxy | Rate limiting intercepts POST /api/paste before route handler; IP extracted from headers |
| Proxy -> Route Handler | Only non-rate-limited requests reach the paste creation handler |
| x-forwarded-for header | Untrusted input from client; first entry trusted only behind reverse proxy |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-05 | Denial of Service | POST /api/paste | mitigate | Rate limiter in proxy: 5 req/min/IP, 429 response with Retry-After header |
| T-04-06 | Elevation of Privilege | x-forwarded-for spoofing | accept | First IP from x-forwarded-for trusted behind reverse proxy. Without proxy, rate limiting is best-effort. Acceptable for a pastebin. |
| T-04-07 | Tampering | Rate limiter bypass via varied IPs | accept | In-memory per-IP tracking. Distributed attacks require many IPs; out of scope for single-instance pastebin. |
</threat_model>
