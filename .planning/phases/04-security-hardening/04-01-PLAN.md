<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> Server | All HTTP requests cross this boundary; CSP headers constrain browser behavior after response |
| Client IP -> Rate Limiter | IP address extracted from headers; can be spoofed if no trusted reverse proxy |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | Browser script execution | mitigate | CSP script-src 'self' + SRI sha256 hashes block unauthorized inline/external scripts |
| T-04-02 | Tampering | MIME type sniffing | mitigate | X-Content-Type-Options: nosniff prevents browser from reinterpreting content types |
| T-04-03 | Spoofing | Clickjacking via iframe | mitigate | frame-ancestors 'none' + X-Frame-Options: DENY prevent embedding in frames |
| T-04-04 | Information Disclosure | Referrer leakage | mitigate | Referrer-Policy: strict-origin-when-cross-origin limits referrer data sent cross-origin |
| T-04-05 | Denial of Service | Paste spam | mitigate | Rate limiter module with 5 req/min/IP threshold (wired in Plan 02) |
| T-04-06 | Elevation of Privilege | IP spoofing for rate limit bypass | accept | x-forwarded-for first IP is trusted behind reverse proxy; acceptable risk for a pastebin |
</threat_model>
