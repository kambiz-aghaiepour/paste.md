The cycle function advances system to light, light to dark, dark to system per UI-SPEC interaction contract. Render a button with onClick={cycle}, aria-label="Current theme: {theme}", and min-h-[44px] min-w-[44px] for D-12 touch targets. ## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Inline script in head | FOWT prevention script runs before React hydrates; must be allowed by CSP |
| localStorage read | Theme script reads user preference from browser storage |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Elevation of Privilege | theme-script.tsx inline script | mitigate | CSP script-src allows only the exact script via SHA-256 hash; script content is static and deterministic |
| T-05-02 | Information Disclosure | theme-toggle.tsx localStorage read | accept | Script reads only paste-md-theme key (a UI preference, not PII); no data exfiltration risk |
| T-05-03 | Tampering | localStorage paste-md-theme value | accept | Tampered value causes wrong theme (cosmetic), not a security impact; toggle recovers immediately |
</threat_model>
