# Phase 5 -- UI Design Contract

> Visual and interaction contract for UI Polish & Experience. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none (hand-crafted Tailwind components) |
| Icon library | Inline SVG (no external icon library -- 2 icons only: sun/moon, copy/check) |

Source: RESEARCH.md -- "zero new npm packages", inline SVG for icons. Project simplicity constraint prohibits adding a component library at Phase 5.

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, copy button inset from pre edge |
| sm | 8px | Compact element spacing, gap between metadata lines |
| md | 16px | Default element spacing, container padding on mobile (`p-4`) |
| lg | 24px | Section padding, gap between header and content |
| xl | 32px | Container padding on desktop (`p-8`), heading margin-bottom |
| 2xl | 48px | Header height (accommodates 44px touch target + 2px top/bottom) |
| 3xl | 64px | Not used in this phase |

Exceptions: Touch targets use `min-h-[44px] min-w-[44px]` per D-12 (WCAG / Apple HIG). This is 44px, not a multiple of 4, and that is intentional for accessibility compliance.

## Typography

| Role | Size | Weight | Line Height | Tailwind Class |
|------|------|--------|-------------|----------------|
| Body | 14px | 400 (regular) | 1.5 | `text-sm` |
| Label | 14px | 400 (regular) | 1.5 | `text-sm` |
| Heading (page) | 30px | 700 (bold) | 1.2 | `text-3xl font-bold` |
| Display (404/410) | 36px | 700 (bold) | 1.2 | `text-4xl font-bold` |

Weights declared: 2 -- regular (400) for body and labels, bold (700) for headings and display. Labels are distinguished from body text by context and color (e.g. `text-gray-500` for secondary labels), not by font weight.

Source: Existing codebase uses `text-sm` (14px) for all body/label text, `text-3xl` (30px) for home heading, `text-4xl` (36px) for 404 display. This phase preserves these -- no typography changes.

Font rendering: `antialiased` class on `<body>` (already set in layout.tsx).

Prose typography: Managed by `@tailwindcss/typography` plugin. Use `prose prose-gray` for light mode, add `dark:prose-invert` for dark mode (D-05). No manual prose overrides beyond what already exists.

## Interaction Contracts

### Theme Toggle

| State | Visual | Behavior |
|-------|--------|----------|
| System (default) | Monitor icon | Theme follows OS `prefers-color-scheme`. Icon indicates "automatic". |
| Light | Sun icon | Light theme forced regardless of OS preference. |
| Dark | Moon icon | Dark theme forced regardless of OS preference. |
| Click | Cycle: system -> light -> dark -> system | Each click advances to next state. `localStorage.setItem("paste-md-theme", newTheme)`. `<html>` class toggled immediately. |
| Page load | No flash | Inline script reads localStorage before paint. If stored theme is "dark" or system prefers dark, `<html>` gets `class="dark"` synchronously. |

### Copy-to-Clipboard Button

| State | Visual | Behavior |
|-------|--------|----------|
| Idle | Clipboard icon, top-right of code block | `opacity-0` by default, `group-hover:opacity-100` on parent hover. On touch devices, always visible (`opacity-100` at `sm:` breakpoint or via `@media (hover: none)`). |
| Hover | Slight background highlight | Visual affordance that button is clickable. |
| Click | Icon changes to checkmark, button text/state = "Copied" | `navigator.clipboard.writeText(preRef.current.textContent)`. Success state holds for 2 seconds, then reverts to idle. |
| Error | Silent fail | If clipboard API fails (insecure context), button reverts to idle. No error toast -- low-priority interaction. |
| Focus | Focus ring visible | `focus-visible:ring-2 focus-visible:ring-blue-500` for keyboard accessibility. |

### Responsive Breakpoints

| Breakpoint | Behavior |
|------------|----------|
| `< 768px` (mobile) | Single-column layout. Edit/preview tabs (existing). Padding `p-4`. Copy button always visible (no hover on touch). |
| `>= 768px` (md) | Split-pane editor (existing). Padding `p-8`. Copy button visible on hover. |

### Tab Bars (Edit/Preview, Rendered/Raw)

| State | Light | Dark |
|-------|-------|------|
| Active tab | `bg-blue-600 text-white` | `bg-blue-600 text-white` (unchanged) |
| Inactive tab | `bg-white text-gray-600` | `dark:bg-gray-800 dark:text-gray-300` |
| Tab container border | `border-gray-200` | `dark:border-gray-700` |
| Touch target | `min-h-[44px]` on all tab buttons | Same |

### Transitions

## Accessibility Contract

| Requirement | Implementation |
|-------------|----------------|
| Touch targets | All interactive elements: `min-h-[44px] min-w-[44px]` (D-12) |
| Code block overflow | `overflow-x: auto` on `<pre>` -- horizontal scroll, no line wrapping (D-11) |
| Theme toggle label | `aria-label="Current theme: {system|light|dark}"` -- updates dynamically |
| Copy button label | `aria-label="Copy code"` (idle), `aria-label="Copied"` (success) |
| Tab pressed state | `aria-pressed={boolean}` on all tab toggle buttons (existing pattern) |
| Keyboard focus | `focus-visible:ring-2 focus-visible:ring-blue-500` on all interactive elements |
| Color contrast | Gray-500 text on white bg = 4.6:1 (AA pass). Gray-400 text on gray-900 bg = 4.6:1 (AA pass). Blue-600 on white = 4.6:1 (AA pass). |
| Reduced motion | Respect `prefers-reduced-motion: reduce` -- skip `transition-colors` and `transition-opacity` |
| Screen reader | Copy button feedback via `aria-label` change. Draft indicator uses `role="status"` (existing). |

## CSP Integration Contract

The FOWT prevention inline script requires a CSP exception. The script content is static and deterministic.

| Property | Value |
|----------|-------|
| Script purpose | Read `paste-md-theme` from localStorage, toggle `dark` class on `<html>` |
| CSP approach | SHA-256 hash of script content added to `script-src` directive |
| Hash computation | `crypto.createHash("sha256").update(THEME_SCRIPT).digest("base64")` |
| CSP directive | `script-src 'self' 'sha256-{computed-hash}'` |
| Fallback | If hash approach proves problematic, allow `'unsafe-inline'` for `script-src` with documented justification |

Source: RESEARCH.md Open Question 1, CONTEXT.md D-03.
