## Component Inventory

### New Components

#### 1. PasteView (Client Component)

**File:** `app/[slug]/components/paste-view.tsx`
**Purpose:** Wraps paste content with rendered/raw tab toggle (REND-04).
**Source:** CONTEXT.md D-07, D-08, D-09

```
+--------------------------------------------------+
| [ Rendered ]  [ Raw ]                            |  <-- Tab bar
+--------------------------------------------------+
|                                                  |
|  (rendered markdown OR raw <pre> block)          |
|                                                  |
+--------------------------------------------------+
```

**Tab bar specifications:**
- Container: `flex rounded-lg border border-gray-200 overflow-hidden mb-4`
- Active tab: `bg-blue-600 text-white` with `flex-1 py-2 text-sm font-medium text-center`
- Inactive tab: `bg-white text-gray-600` with `flex-1 py-2 text-sm font-medium text-center`
- Default active tab: "Rendered"
- Accessibility: `aria-pressed` on each button, `type="button"` to prevent form submission

This is identical to the Phase 2 edit/preview toggle in `paste-form.tsx` (lines 74-99). Reuse the exact same visual pattern.

**Raw view specifications:**
- Container: `<pre>` element
- Classes: `whitespace-pre-wrap break-words rounded-lg border border-gray-200 bg-gray-50 p-4 font-mono text-sm`
- No line numbers, no syntax highlighting, no additional chrome
- Content: raw paste string passed as text child

**Rendered view specifications:**
- Passes through the `<MarkdownRenderer>` output (pre-rendered React Server Component children)
- No wrapper changes needed; same `prose prose-gray max-w-none` styling as current paste view

**Props:**
- `content: string` -- raw paste content for the Raw tab
- `renderedContent: React.ReactNode` -- pre-rendered markdown from Server Component
- `expiresAt: number | null` -- for optional expiration label display

#### 2. Expiration Dropdown (inline in PasteForm)

**File:** `app/components/paste-form.tsx` (modify existing)
**Purpose:** Let users select paste expiration (STOR-02).
**Source:** CONTEXT.md D-01, D-02

```
+--------------------------------------------------+
|  [textarea...]                                    |
+--------------------------------------------------+
|                                                  |
|  [Never expires v]    [ Create Paste ]           |  <-- form footer row
|                                                  |
+--------------------------------------------------+
```

**Dropdown specifications:**
- Element: native `<select>` (no custom dropdown component)
- Classes: `rounded-lg border border-gray-300 px-3 py-2 text-sm focus:border-blue-500 focus:ring-1 focus:ring-blue-500 focus:outline-none`
- Accessibility: `aria-label="Paste expiration"`
- Default value: `"never"`
- Options (exact text and values):
  - `value="never"` -- "Never expires"
  - `value="1h"` -- "1 hour"
  - `value="1d"` -- "1 day"
  - `value="1w"` -- "1 week"
  - `value="1m"` -- "1 month"

**Layout:** Place the dropdown and submit button on the same row using `flex items-center gap-4`. The dropdown sits on the left, the submit button on the right (`ml-auto` on the button). This keeps the form footer compact and prevents the form from growing taller.

**On mobile:** The row wraps naturally. The select is full-width on very small screens if needed via `w-full sm:w-auto`.

#### 3. 410 Gone Page (inline HTML in proxy.ts)

**File:** `app/proxy.ts`
**Purpose:** Show expired paste message with HTTP 410 status (STOR-03).
**Source:** CONTEXT.md D-05, RESEARCH.md Pattern 2

```
+--------------------------------------------------+
|                                                  |
|                     410                          |  <-- gray-400, text-4xl, font-bold
|                                                  |
|           This paste has expired.                |  <-- gray-500, body text
|                                                  |
|              Back to home                        |  <-- blue-600 link
|                                                  |
+--------------------------------------------------+
```

**Specifications:**
- Layout: centered vertically and horizontally (flexbox, `min-height: 100vh`)
- Font: `system-ui, -apple-system, sans-serif` with `-webkit-font-smoothing: antialiased`
- Heading "410": `font-size: 2.25rem; font-weight: 700; color: #9ca3af; margin-bottom: 1rem`
- Body "This paste has expired.": `color: #6b7280; margin-bottom: 2rem`
- Link "Back to home": `color: #2563eb; text-decoration: none` (href="/")
- No Tailwind classes (this is inline-styled HTML returned from proxy.ts, outside the React tree)

This mirrors the existing `not-found.tsx` pattern exactly, substituting "410" for "404" and "This paste has expired." for "Paste not found".

### Modified Components

#### 4. Paste Page (Server Component modification)

**File:** `app/[slug]/page.tsx`
**Purpose:** Wire PasteView wrapper and pass expiration data.

**Changes:**
- Import `PasteView` from `./components/paste-view`
- Replace direct `<MarkdownRenderer>` with `<PasteView>` wrapper
- Pass `content`, `renderedContent` (wrapping `<MarkdownRenderer>`), and `expiresAt`
- Optionally display "Expires in X" label if `paste.expiresAt` is set and in the future

**Expiration label (recommended, Claude's Discretion):**
- Display below the paste content, next to the "Created:" timestamp
- Format: "Expires in 6 days" / "Expires in 3 hours" (human-readable relative time)
- Classes: `text-sm text-gray-500` (same as "Created:" line)
- If `expiresAt` is null: do not show any expiration label
- Compute relative time with a simple utility (no library needed for rough approximation)

## Responsive Behavior

### Expiration Dropdown + Submit Button Row
- **Desktop (sm+):** Horizontal row -- dropdown on left, button on right
- **Mobile (<sm):** Dropdown full-width above button, both stacked vertically

### Tab Bar (Rendered/Raw)
- **All sizes:** Full-width tab bar above content. No responsive changes (same as Phase 2 mobile toggle, but shown at all breakpoints)

### 410 Page
- **All sizes:** Centered content, responsive by default (flexbox centering). No breakpoint-specific changes.

## Accessibility

| Requirement | Implementation |
|-------------|---------------|
| Tab toggle keyboard | Native `<button>` elements, keyboard-accessible by default |
| Tab toggle screen reader | `aria-pressed` on each button communicates active state |
| Expiration dropdown | Native `<select>` with `aria-label="Paste expiration"` |
| 410 page | Semantic HTML (`<h1>`, `<p>`, `<a>`), `lang="en"` on `<html>` |
| Raw view | `<pre>` preserves whitespace; screen readers announce as preformatted text |
| Focus management | No focus traps; tab order follows DOM order naturally |
