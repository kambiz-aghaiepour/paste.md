## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> POST /api/paste | Untrusted expiration string from browser form |
| Client -> proxy.ts | Untrusted URL path segment used as database query key |
| External cron -> DELETE /api/cleanup | Untrusted Authorization header (covered in Plan 02) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | POST /api/paste | mitigate | Validate expiration against VALID_EXPIRATIONS allowlist; reject unknown values with 400 |
| T-03-02 | Tampering | Client timestamp | mitigate | Server computes expiresAt from createdAt + duration per D-03; never trust client-computed timestamps |
| T-03-03 | Information Disclosure | GET /api/paste/:id, GET /api/paste/:id/raw | mitigate | Check expiration in all three routes (proxy, JSON API, raw API) per Pitfall 6 |
| T-03-04 | Denial of Service | proxy.ts | accept | Each proxy invocation does one SQLite read (sub-ms); matcher constrains to 8-char slug paths only |
| T-03-05 | Spoofing | proxy.ts slug extraction | mitigate | Matcher regex constrains to [A-Za-z0-9_-]{8}; only valid nanoid patterns reach the database |
</threat_model>
